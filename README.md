# Movie Discovery App

A responsive movie discovery web application built with React, Node.js, Express, MongoDB, and OMDb API.
Users can search for movies, view detailed movie information, and save movies to a persistent wishlist.

---

# Features

- Search movies
- Pagination / Load More
- Movie details page
- Persistent wishlist
- Remove movies from wishlist
- Debounced search
- API error and empty-result handling
- Responsive design
- Backend API abstraction layer

---

# Tech Stack

## Frontend

- React.js
- TailwindCSS
- Zustand
- React Router DOM
- Axios

## Backend

- Node.js
- Express.js
- MongoDB
